Фото для блока «Реализованные проекты» на главной.

1. Положите сюда фото стенда: JPG, PNG или WebP, лучше по длинной стороне 1600–2000 px,
   горизонтальное (карточка обрезает фото до 4:3 по центру).
2. В content/home.json, в блоке "projects", впишите путь в поле "image" нужной карточки,
   например "home/project-1.webp" (путь считается от content/media/).
   То же можно сделать в админке: «Тексты» → «Проекты: Реализованные проекты».
3. Заполните известные поля: title (название), event (выставка), area (площадь), place (город).
   Неизвестное оставьте пустым — на сайте оно не появится.
4. Проверьте: flask --app app check-content

Если проект уже есть в портфолио, вместо фото можно указать его id в поле "project" —
тогда карточка возьмёт название, город, площадь и фото из портфолио.
